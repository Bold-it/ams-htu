# HTU Accreditation Monitoring System - cPanel Deployment Guide

This guide provides step-by-step instructions for deploying the HTU Accreditation Monitoring System on a cPanel environment.

## 1. Database Setup
1.  Log in to your cPanel account.
2.  Go to **MySQL® Databases**.
3.  Create a new database named `htu_accreditation`.
4.  Create a new MySQL user (e.g., `htu_admin`) and a strong password.
5.  Add the user to the database and grant **ALL PRIVILEGES**.
6.  Go to **phpMyAdmin**.
7.  Select the `htu_accreditation` database.
8.  Click on the **Import** tab and upload the `database_setup.sql` file provided in this folder.

## 2. Backend (Node.js) Deployment
1.  ZIP the contents of the `backend` folder (exclude `node_modules` and `.env`).
2.  In cPanel, go to **Setup Node.js App**.
3.  Click **Create Application**.
4.  Set Application root to `accreditation-api`.
5.  Set Application URL to `api.yourdomain.com` (or a subfolder like `yourdomain.com/api`).
6.  Set Application startup file to `server.js`.
7.  Click **Create**.
8.  Upload your ZIP file to the `accreditation-api` folder using **File Manager** and extract it.
9.  Back in the Node.js App setup, add the following **Environment Variables**:
    *   `PORT`: `3000` (or as assigned by cPanel)
    *   `DB_HOST`: `localhost`
    *   `DB_USER`: `your_mysql_user`
    *   `DB_PASSWORD`: `your_mysql_password`
    *   `DB_NAME`: `htu_accreditation`
    *   `JWT_SECRET`: `your_long_random_secret_string`
    *   `EMAIL_USER`: `accreditationsystem@htu.edu.gh`
    *   `EMAIL_PASS`: `your_email_app_password`
    *   `FRONTEND_URL`: `https://accreditation.htu.edu.gh`
10. Click **Run NPM Install**.
11. Click **Restart**.

## 3. Frontend (Static) Deployment
1.  Go to the `dist` folder generated by the build process.
2.  ZIP the contents of `dist`.
3.  In cPanel, upload the ZIP to your public directory (e.g., `public_html` or a subdomain folder).
4.  Extract the ZIP.
5.  Ensure there is an `.htaccess` file to handle React routing:
    ```apache
    Options -MultiViews
    RewriteEngine On
    RewriteCond %{REQUEST_FILENAME} !-f
    RewriteCond %{REQUEST_FILENAME} !-d
    RewriteRule ^ index.html [L]
    ```

## 4. Final Verification
1.  Visit your frontend URL.
2.  Attempt to log in with `super_admin` and your password.
3.  Verify that data is loading and the dashboard is functional.
4.  Test a simple PDF report generation.

---
**Note:** For email reminders to work, ensure the server's firewall allows outgoing SMTP connections (usually ports 465 or 587).
