# Proposal: HTU Accreditation Monitoring System v1.1
**Strategic Enhancements for Institutional Quality Assurance**

---

## 📅 Executive Summary
The HTU Accreditation Monitoring System (v1.0) has successfully established a secure, centralized, and reliable platform for tracking academic programmes. We have achieved core stability in **Email Notifications**, **Departmental Security Isolation**, and **Performance**.

As we look to the next phase (v1.1), the focus shifts from *tracking* to *strategic management* and *administrative efficiency*.

---

## 🚀 Key Proposed Features for v1.1

### 1. 🔍 Strategic Compliance Heatmapping
*   **Feature**: An interactive "Renewals Forecast" chart covering the next 18–24 months.
*   **Institutional Value**: Allows the Quality Assurance Unit to see months with high renewal density in advance, preventing "bottlenecks" during the GTEC renewal process.
*   **Benefit**: Better resource allocation and staff workload management.

### 2. 📦 Faculty-wide Portfolio Export (Bulk ZIP)
*   **Feature**: A single-button tool to download all stored certificates and supporting documents for an entire Faculty or School.
*   **Institutional Value**: Simplifies preparation for external GTEC visitations or internal audits by gathering all proof-of-compliance in seconds.
*   **Benefit**: Saves hundreds of manual hours currently spent downloading individual files.

### 3. 📡 Real-time "System Heartbeat" Monitoring
*   **Feature**: A visual dashboard indicator showing the live status of the Mail Server and Database connection.
*   **Institutional Value**: Provides immediate assurance to senior management that the automated 15-month warning system is operational without needing technical intervention.
*   **Benefit**: Increases operational transparency and trust in the digital system.

### 4. ✍️ Dynamic Email Template Customization
*   **Feature**: A secure UI where the Super Admin can update the wording, logos, and signatures of automated reminder emails.
*   **Institutional Value**: Allows the system to adapt to official policy changes or rebranding without requiring code modifications.
*   **Benefit**: Institutional self-sufficiency and reduced maintenance overhead.

---

## 🛠️ Technical Security & Stability (Continuous)
*   **Unified Authentication**: Final transition to 100% JWT-only security, removing all legacy fallback mechanisms.
*   **Automatic Cloud Backup**: Implementation of "Snapshots" for the daily database backups to ensure 0% data loss risk across HTU servers.

---

## 📊 Expected Outcomes
1.  **Reduced Compliance Risk**: Targeted heatmapping prevents missed deadlines during peak periods.
2.  **Increased Administrative Speed**: Bulk exports reduce audit preparation time by over 90%.
3.  **Enhanced Reliability**: Real-time monitoring ensures zero downtime for critical email alerts.
